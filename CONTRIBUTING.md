# Contributing

¡Gracias por tu interés en contribuir a este proyecto!

Todas las contribuciones, informes de errores, correcciones de errores, mejoras de documentación, mejoras de funcionalidades e ideas son bienvenidas.

## Cómo Contribuir

### 1. Reportar Problemas

Si encuentras un error o comportamiento inesperado:

* Verifica primero si ya existe un issue similar.
* Describe claramente el problema.
* Incluye pasos para reproducirlo.
* Adjunta capturas de pantalla o registros cuando sea posible.

### 2. Proponer Mejoras

Las sugerencias para mejorar el proyecto son bienvenidas.

Al crear una propuesta, intenta incluir:

* Descripción del problema que resuelve.
* Beneficios esperados.
* Posibles alternativas consideradas.

### 3. Contribuir con Código

1. Haz un fork del repositorio.
2. Crea una rama para tu cambio:

```bash
git checkout -b feature/nueva-funcionalidad
```

3. Realiza los cambios necesarios.
4. Verifica que el proyecto siga funcionando correctamente.
5. Realiza commits claros y descriptivos.
6. Envía un Pull Request.

### Convención de Commits

Se recomienda utilizar mensajes descriptivos como:

```text
feat: agregar sistema de autenticación
fix: corregir error en el formulario de registro
docs: actualizar documentación de instalación
refactor: simplificar lógica del componente usuario
```

## Estándares de Código

* Mantener el código legible y documentado.
* Seguir el estilo existente del proyecto.
* Evitar cambios no relacionados en un mismo Pull Request.
* Eliminar código muerto o sin uso cuando corresponda.

## Documentación

Las mejoras de documentación son tan valiosas como las contribuciones de código.

Puedes colaborar:

* Corrigiendo errores ortográficos.
* Mejorando explicaciones.
* Añadiendo ejemplos.
* Actualizando información desactualizada.

## Proceso de Revisión

Todos los Pull Requests serán revisados antes de ser integrados.

Durante la revisión es posible que se soliciten cambios o aclaraciones para garantizar la calidad y consistencia del proyecto.

## Código de Conducta

Al participar en este proyecto, aceptas respetar el Código de Conducta y contribuir a mantener una comunidad respetuosa, inclusiva y colaborativa.

## Licencia

Al enviar contribuciones, aceptas que tu trabajo sea distribuido bajo la misma licencia que utiliza este proyecto.

¡Gracias por ayudar a mejorar este proyecto!
