# simple-interest-calculator
# Proyecto Web de Gestión de Tareas

Aplicación web desarrollada para facilitar la organización y seguimiento de tareas personales y de equipos. Permite crear, editar, eliminar y clasificar tareas según su estado de avance, prioridad y fecha límite.

El sistema cuenta con una interfaz intuitiva y responsiva, diseñada para ofrecer una experiencia fluida tanto en dispositivos de escritorio como móviles. Además, incorpora funcionalidades como filtrado dinámico, búsqueda de tareas, categorías personalizadas y almacenamiento persistente de datos.

### Características principales

* Creación y gestión de tareas.
* Edición y eliminación de registros.
* Filtros por estado, prioridad y categoría.
* Búsqueda en tiempo real.
* Diseño responsive.
* Persistencia de datos.
* Interfaz moderna y fácil de usar.

### Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* React
* Node.js

### Objetivo

El objetivo de este proyecto es aplicar conceptos de desarrollo frontend y backend para construir una aplicación completa, escalable y fácil de mantener, siguiendo buenas prácticas de programación y diseño de software.
